💡IDEAS Standard Course Converter

Paste or upload an old Canvas page's HTML to get it in the standard template.

What the converter does

  • Loads the Module Overview layout and optional snippets from the resource library. Use Template and snippets to choose, edit and add snippets.
  • Puts the page's first heading (or the Module Title) in the navy title banner.
  • Keeps all wording, images, videos and links exactly as they are. URLs and embed attributes are never changed.
  • Turns other headings and bold-only lines into navy subheadings.
  • If the page has an Assignment Checklist, To Do List or similar, rebuilds it as the standard To Do List with a bolded action verb on each item. Learning objective codes are kept only where an item already lists them.
  • If there is no checklist, the page is formatted without a To Do List.
  • Every page ends with the thick navy line.
  • Removes faculty notes, template placeholder text, outer wrapper boxes, old divider lines, Word formatting, and inline fonts, font sizes and text alignment.
