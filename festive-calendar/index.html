    Sync across computers

    Your calendar and to-do list are saved to a private file in your own GitHub account, so every computer you connect sees the same list. This browser keeps its own copy too, so it still works offline.

    1. Open this GitHub page (sign in if asked). The gist box is already ticked.
    2. Choose an expiration (for example, 1 year), then press Generate token at the bottom.
    3. Copy the code that starts with ghp_ and paste it below. Do this once on each computer.
