⚡ Quick formatting

  • First lineBlue title banner
  • ## SectionHeading (or a Title Case line)
  • ### SubSmaller heading
  • - itemBullet list; 1. for numbers
  • Read:Short label made bold
  • Tip:Call-out box (also Remember:)
  • **bold**Bold; *italic* for italic
  • ---Divider line

🔗 Links, video, tables

  • https://…Link that opens in a new tab
  • [Text](url)Descriptive link text
  • YouTube URLAlone on a line: embedded video
  • a | bTable row (or tab-separated). First row is the header.
  • Caption:Line above a table becomes its caption
More rules ▾
  • Section names like Module Overview, To Do List, Purpose, Directions, Resource 1: …, Step 1: … or Connect to Practice become styled headings.
  • Each line is its own paragraph. Indent two spaces to nest a list.
  • Pasting from Word or Google Docs keeps headings, bold, lists, links and tables.
  • Snippets, Quick Checks, Flashcards and emoji are added on the Edit tab.
